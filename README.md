# VastraVault
VastraVault is a web-based inventory management and business analytics prototype designed for Indian boutiques and small fashion retailers. It provides an interface for managing products, monitoring inventory, handling customer and order information, and visualizing business insights.
Features
Inventory Management: Browse, search, filter, and manage clothing product information.
Sales Dashboard: Visualize sales and inventory-related information.
Analytics: Display charts and business insights using Chart.js.
Customer Management: Explore customer information through a dedicated interface.
POS Interface: Perform shopping cart and billing calculations.
Order Management: View and manage sample order information.
Boutique-focused UI: A custom-designed interface for fashion retail workflows.

Tech Stack
HTML5
CSS3
JavaScript (ES6+)
Chart.js 4.4.7
