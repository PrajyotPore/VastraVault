# VastraVault
### Boutique Inventory Management & Business Analytics

VastraVault is a web-based inventory management and business analytics prototype designed for Indian boutiques and small fashion retailers. It provides a centralized interface for managing clothing products, exploring inventory, viewing sales analytics, and handling customer and order information.
## Website
https://vastravault.netlify.app/
## Features

- **Inventory Management:** Browse, search, and filter clothing products.
- **Sales Dashboard:** View sales and inventory-related visualizations.
- **Business Analytics:** Explore charts and insights using Chart.js.
- **Customer Management:** Access customer information through a dedicated interface.
- **Point of Sale (POS):** Perform shopping cart and billing calculations.
- **Order Management:** View and manage sample order information.
- **Boutique-Focused UI:** A custom interface designed around fashion retail workflows.

## Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and layouts
- **JavaScript (ES6+)** — Interactions and application logic
- **Chart.js 4.4.7** — Data visualization

##  Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (recommended)

## Project Status

**Current status:** Frontend prototype.

The current implementation uses predefined demonstration data. Backend integration, persistent database storage, and advanced data-driven forecasting are potential future enhancements.

## Future Enhancements

- Integrate a backend and database for persistent storage.
- Implement secure user authentication.
- Add automated low-stock notifications.
- Develop sales-based dead-stock detection.
- Introduce demand forecasting using historical sales data.
- Enable inventory reports and data export.

## Objective

To make inventory management and business analytics more accessible to small fashion retailers, helping them organize stock and make informed business decisions.

## Developed As

A hackathon project focused on improving inventory management and data-driven decision-making for boutique businesses.
